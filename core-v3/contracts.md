# Verträge für die Arbeit an Core V3

Diese Verträge dienen der Selbstverwaltung des Agenten bei der Arbeit an
`core-v3`.

## Kompakter Code

Code muss kompakt und prägnant gehalten werden. Es wird sparsam programmiert:
Nur Code, Abstraktionen, Abhängigkeiten und Dateien anlegen, die für die
aktuelle Aufgabe tatsächlich erforderlich sind. Wiederholungen und unnötige
Schichten vermeiden, ohne Lesbarkeit, Typsicherheit oder Korrektheit zu
opfern.

## Mitteilung bei Vertragsänderungen

Der Agent muss ausdrücklich mitteilen, wenn Verträge hinzugefügt, geändert
oder entfernt wurden. Die Mitteilung nennt kurz, welche Verträge betroffen
sind und was sich an ihnen geändert hat.
